# Sell-Out & Distribution Analytics Platform

Projeto de Engenharia de Dados focado em integração, tratamento, qualidade e análise de dados de distribuição e sell-out utilizando Databricks, PySpark e arquitetura Lakehouse.

## Stack
- Databricks
- PySpark
- Delta Lake
- SQL
- Python

## Objetivo
Simular um ambiente corporativo de distribuição e varejo com foco em ingestão, transformação, qualidade e análise de dados.
